Code By AI is a unified API gateway for AI coding agents. Instead of separate accounts and API keys for Anthropic, OpenAI and Google, developers get one key and one prepaid balance that works across Claude, GPT/Codex and Gemini models, and point tools such as Claude Code, Codex CLI, Gemini CLI, OpenCode, Cline and Trae at its base URL.

The same key speaks Anthropic Messages, OpenAI Responses, OpenAI Chat Completions and Google Gemini formats, and requests are forwarded as-is so streaming and tool calls behave as each client expects. Pricing is pay-as-you-go per token, listed next to each vendor's official price; creating an account is free, and API calls require a top-up.
