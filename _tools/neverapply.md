NeverApply's hosted MCP server lets Claude, Cursor, Cline and other MCP clients search and match jobs, tailor resumes, answer screening questions, prepare for interviews, and apply to jobs with your approval. OAuth sign-in over Streamable HTTP at https://neverapply.co/mcp. Docs: https://neverapply.co/features/mcp. Public repo: https://github.com/kasovy/neverapply-mcp (MIT).
