Kite is a design tool that AI agents and people use in the same file. Claude, ChatGPT, Cursor or Codex connect through Kite's hosted MCP server (https://kite.new/api/mcp) and draw editable layers instead of flat images, while the team edits and comments live. Frames can be copied to Figma or out as HTML, React or Tailwind. The free plan includes unlimited editors, 3 files and 200 agent actions a day; Pro is $16 per editor a month billed yearly.
