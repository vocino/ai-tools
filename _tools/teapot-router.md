Teapot Router routes Claude Code, Codex CLI, and OpenAI-SDK traffic through a single API key: set two environment variables (ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN) and your existing tools just work, no vendor lock-in. Pricing is public and machine-readable — a JSON endpoint serves the same rates the console charges — so agent costs can be audited per request instead of guessed. New signups get a small amount of trial credit; top-ups start at $1, never expire, and are refundable on remaining balance.
