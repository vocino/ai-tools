Teapot Router is a team API gateway for GPT and Claude Code workloads. One shared token pool serves the whole team, every request is metered — model, tokens in/out, cache hits, exact cost — so spend reconciles line by line, and the price book is public without login, showing the official base rate next to the actual rate for every model. Dual protocol: Anthropic /v1/messages for Claude Code and OpenAI-compatible endpoints for Codex-style tools. Prepaid from $1, credit never expires.
