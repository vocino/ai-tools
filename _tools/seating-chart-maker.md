Seating Chart Maker helps event and classroom organizers arrange tables, import a guest list, and assign seats in a browser. It can create a starting layout and apply seating rules, while allowing users to review and adjust assignments manually. The site offers planning features to try, with a paid plan required to save or export the finished plan.
