Tale is a project workspace where teams assign tasks to agents, provide shared context, and review their returned reports and files. Community software is MIT-licensed and free to self-host; infrastructure and model usage have separate costs. Its documented API and MCP endpoint run on the team's own deployment with authentication, and agent assignments require an explicit start. See the [repository](https://github.com/tale-project/tale), [project-agent guide](https://docs.tale.dev/platform/projects/project-agents), [installation guide](https://docs.tale.dev/self-hosted/install/quickstart), and [MCP documentation](https://docs.tale.dev/develop/mcp-endpoint).
