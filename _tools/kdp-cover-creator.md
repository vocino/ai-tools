KDP Cover Creator is a browser-based workspace for designing and revising book covers. Authors and designers can arrange front, spine and back layouts, check dimensions and export a full-wrap PDF while retaining an editable project backup. Optional AI-assisted artwork uses credits; users should independently check image rights and current printer specifications. The product is independent and is not an official Amazon service.
