LUT Generator is a browser-based reference color matching tool for photos and SDR video frames. Local matching, manual adjustments and PNG exports are free, while custom `.cube` exports use credits. Optional AI assistance sends a reduced preview for processing, and export validation sends the color table. Test a look across representative frames and review the processing notes before using confidential images.
