Skybox Generator is a browser-based tool for creating panoramic environments from a written scene description and optional reference images. Its interface provides a spherical preview and controls for reviewing the horizon and wrap before export. The site describes PNG panorama and six-face cubemap exports, with credits used for generation and paid plans available.
