LurkAPI is a social media data API. Send one GET request and get clean JSON from public pages on 16 platforms, including TikTok, Instagram, YouTube, Reddit, X and LinkedIn: profiles, posts, comments, video transcripts and the ads in Meta's, Google's, TikTok's and LinkedIn's ad libraries. The same endpoints work as an MCP server (https://api.lurkapi.com/mcp), so an agent can look things up directly instead of answering from memory. It reads public data only and can't post or message anyone. Docs: https://lurkapi.com/docs. Pricing: https://lurkapi.com/pricing.
