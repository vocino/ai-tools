Meta AI at dev.meta.ai is Meta's developer platform for building with its Llama family and Muse Spark. The Model API provides hosted access to Llama 3 and Llama 4 with streaming, tool use, and multimodal input, alongside SDKs for Python and JavaScript. Developers can prototype in the playground, integrate Muse Spark for code generation, and fine-tune models for production use, complementing the open-source weights available via Meta Llama.
